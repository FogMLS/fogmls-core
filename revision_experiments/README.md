# Scripts and results for the revised experiments

These scripts produced the new results added in the revised manuscript. They were run on a Slurm cluster with the corrected GA from the main repository (mutation step fixed on 16 November 2026).

| Files | What they do |
|---|---|
| `r1_fixed.py`, `r1_fixed10.py`, `r1_1_workloads.py` | Run the simulator under different loads: slot length, task mixes and node profiles |
| `r1_fixedpop.py`, `scale_pop.py`, `scale_rerun.py` | Population size and scalability tests |
| `rf_fixed*.py`, `rf_plain.py`, `rf_workloads.py`, `train_fx*.py`, `paired_rf*.py` | Train the Random Forest classifier and run it in the simulator |
| `r1_3_pso.py`, `r1_3_mix.py` | PSO-label classifier test |
| `r1_tie.py`, `r1_time.py`, `time_rf.py`, `r1_4_check.py` | Tie tolerance sweep, timing, and the train/test split check |
| `runs.csv` | The result of every run (latency, cloud tasks, energy) |

Datasets, trained models and logs are not included. They can be regenerated by running `IoTsimulation.py` from the main repository with the same random seed. Some scripts use relative paths such as `./FX10_BASE/` and expect the regenerated datasets in the same folder.
